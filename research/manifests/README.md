## 字段与评级

CSV 采用 UTF-8，所有字段都加双引号，便于后续 TypeScript、Python、SQLite 或表格工具稳定读取。关键字段：

- `record_id`：本项目内稳定主键；不要用标题当主键。
- `teacher_key`：发布主体层面的教师标识；实名未核实时不得擅自合并。
- `video_id`：单集为 BVID；多 P 视频采用 `BVID#pN`，并同时保存 `part_no` 与 CID。
- `source_confidence`：对“此 URL 确由该发布账号公开”的置信度，不代表教学质量。
- `content_fit`：与受力分析、共点力平衡、牛顿第二定律范围的匹配度。
- `visual_fit`：本轮没有逐帧观看，统一为 `unknown_pending_manual_watch`，避免把标题推断伪装成视觉事实。
- `recommend_observation`：是否进入首轮 3–6 小时人工观察；不是训练许可。
- `selection_reason` / `exclusion_reason`：保留选择逻辑，防止后续只凭播放量改名单。

权利等级：

- `green`：明确开放许可（例如 CC）或权利方书面授权，且用途覆盖预定处理。本轮为 0 条。
- `yellow`：教师本人/官方账号公开可看，但未明确授予下载、复制、抽帧、转写入库、训练或再发布权。本轮 10 条先做人工作品分析；后续如按项目决策进入非商业内部研究，必须保持私有、最小化、可追溯和可删除，并承认仍存在平台与著作权适用的不确定性。
- `red`：搬运、付费课泄露、网盘、登录/DRM限制、发布主体不明或权利明显冲突。首轮不得观察性入库，更不得采集。本 CSV 不保存红色资源 URL，避免形成错误采购清单。

## 人工观察门槛

进入下一步前，对 `recommend_observation=yes` 的每条至少由两人各看 10–15 分钟，并记录：

1. 画面是否持续可见，板书/课件文字是否可读；
2. 是否真的画出规范受力图，箭头、作用点、研究对象和坐标轴是否明确；
3. 音画是否同步，教师说到“画图/看图/这个力”时能否定位到画面动作；
4. 是否包含启发式提问、错误诊断、类比、分步提示和总结；
5. 是否有广告、静音、长等待、重复直播或与本单元无关片段；
6. 记录可比较片段的时间戳，但在未获许可前不要抽帧、下载音频或生成持久化转写。

若一条视频的图示不可读或教师画图动作不可见，`visual_fit` 改为 `low`，并把 `recommend_observation` 改为 `no`；不要因教师名气保留。
