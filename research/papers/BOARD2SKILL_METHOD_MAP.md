# Board2Skill-Opt 论文方法映射

这份文档把六篇核心参考论文放入同一条研究链路，区分论文原始贡献、本项目借鉴模块和必须自行解决的教育场景问题。

## 1. 模块映射

| 模块 | 主要参考 | 可借鉴机制 | 本项目必须新增 |
|---|---|---|---|
| 多模态初始蒸馏 | Resource2Skill | 视频、文本、视觉、程序与来源组织 | 板书时序、观察事实与意图分离、教师路径质量标签 |
| 外部验证锚点 | OpenSkill | 独立检索验证知识、虚拟任务、缺口与错误诊断 | 学科硬约束、专家校准、真实学习效果边界 |
| Skill 文本优化 | SkillOpt | 有界编辑、独立选择集、拒绝缓冲、快慢更新 | 多目标门、学生子群约束、Skill 分裂合并与路由 |
| 按需 Skill 路由 | ProActAgent | 类型化经验库、检索/不检索配对分支 | 多模态黑板状态、不可精确回放的真实学生会话 |
| 动态教学环境 | Agent-World | 状态化环境、动态诊断 Arena、能力缺口课程 | 受控学生知识状态与误解算子，不能自由幻想学生 |
| 轨迹驱动课程进化 | Socratic-SWE | 成败轨迹到 Skill Registry、验证门、定向造题 | 教学奖励、答案泄露、认知负担和最差学生组约束 |

## 2. 统一闭环

```text
教师视频
→ 不可变 Observation Trace
→ 多解 Intent Hypothesis
→ Teacher Replay 与反事实策略候选
→ TeachingWorld 受控 Rollout
→ 成功 / 失败 / 部分成功轨迹
→ Conditional Teaching Skill Registry
→ 动态生成能力边界场景
→ 结构 / 证据 / 可执行 / 教学四级门
→ 独立 selection 集晋升或拒绝
→ 版本化 Skill、路由器和回滚记录
```

视频是“教师实际做了什么”的证据真值；教材、学科规则和专家 rubric 是正确性锚点；受控 Rollout 与选择集才是“Agent 应该怎么教”的策略证据。

## 3. 现在采用

1. 双源初始化：教师视频生成候选策略，教材与规范图例生成独立验证锚点。
2. 类型化经验库：观察证据、事实、教学情节、成功策略、失败反模式、优劣对照和验证规则分开保存。
3. 成对反事实：在相同学生状态、对话前缀和黑板状态上比较 Teacher Replay、修复策略、检索与不检索。
4. 四级验证门：结构完整、证据可追溯、工具可执行、教学场景能区分好坏策略。
5. 严格晋升：硬约束通过、核心指标提升、最差学生组不明显退化，才进入正式 Skill。

## 4. 后续采用

1. 根据失败分布动态生成训练场景，而不是长期使用固定 24 题。
2. 验证驱动的 Skill 分裂、合并、条件路由和主动检索。
3. 使用真实会话日志进行离线回放、shadow 和 canary 验证后再晋升。
4. 数据和算力充足后，再研究上下文 bandit、策略参数训练或模型权重强化学习。

## 5. 不直接照搬

- 不把自建验证器分数当真实学习增益。
- 不让同一个模型同时生成学生、教师、任务和裁判而缺少隔离。
- 不采用“最后一次修改就是最终 Skill”，始终保存历史最佳和回滚版本。
- 不强制每条轨迹写入经验库，允许 `NO_WRITE`。
- 不把最难场景等同于最有训练价值。
- 不在早期复制需要大量 GPU 的模型权重训练；先验证外部 Skill 优化是否有效。

## 6. 第一轮实验

用现有物理视频和 24 个受控教学场景比较：

1. Base Tutor；
2. Teacher Replay；
3. Resource2Skill 式一次性蒸馏；
4. 固定场景 SkillOpt；
5. Board2Skill-Opt：双源锚点、反事实候选、类型化经验、四级验证门和严格晋升。

优先报告知识与图形错误、虚构学生行为、近迁移、补救成功、无效 Skill 调用率、成本和最差学生组表现。模拟学生结果只作为代理筛选信号，不声称真实学习效果。
